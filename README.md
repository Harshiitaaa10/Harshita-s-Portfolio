# Harshita Singh – Portfolio

Static portfolio website (HTML, CSS, JavaScript). No installation or build step.

## Run in VS Code
1. Unzip the folder and open it in VS Code (File > Open Folder).
2. Right-click `index.html` > "Open with Live Server" (install the Live Server extension), or just double-click `index.html` to open it in a browser.

## Structure
- `index.html` – page content (edit your text here)
- `css/style.css` – styling and colors
- `js/script.js` – filters, dark mode, copy buttons, menu
- `assets/profile.jpg` – profile photo (replace with a new one, same name)
- `assets/Harshita_Singh_Resume.pdf` – resume used by the Download button (replace to update)

## Deploy
Drag the whole folder to Netlify, or push it to GitHub and import into Vercel.
